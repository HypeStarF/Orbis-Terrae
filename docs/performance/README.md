# Performance benchmark history

Performance measurements are evidence tied to a specific workload, Java version, operating system, and
machine. They are not universal hardware requirements.

## Atlas runtime

- [Phase 1 atlas runtime benchmark and exit audit](../phase-1/step-11-performance-and-exit-audit.md)

The dedicated `Atlas Runtime Benchmark` workflow uploads its machine-readable JSON report for each run.
Future benchmark records should retain the workload and result fingerprints so regressions can be
separated from intentional workload changes.
