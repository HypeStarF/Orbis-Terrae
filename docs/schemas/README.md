# Schema drafts

These Phase 0 schemas define stable envelopes only. They are intentionally incomplete and must not be
considered final Phase 1 formats.

- `world-profile.schema.json`: editable pre-world-creation profile envelope.
- `world-manifest.schema.json`: immutable world identity envelope.
- `atlas-manifest.schema.json`: versioned atlas identity and layer list.
- `dataset-provenance.schema.json`: evidence required for dataset use.
